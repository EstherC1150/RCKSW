2. 핵심 로직 및 데이터 흐름

🔄 버전 관리 시스템 (Version Chain)

본 프로젝트의 핵심은 component_id를 통한 그룹화입니다.

  • 신규 등록: 새로운 컴포넌트 생성 시 자신의 ID가 component_id가 됩니다.
  • 버전 업데이트: 기존 컴포넌트 ID를 상속받은 신규 행을 추가(INSERT)하여 기록을 유지합니다.
  • 조회 로직: 목록 조회 시 RankedFiles (ROW_NUMBER)를 사용해 최신 버전만 노출하고, 전체 내역 중 가장 빠른 날짜를 최초 등록일로 계산합니다.
// 핵심 SQL 쿼리 전략 (sql.js)
WITH RankedFiles AS (
  SELECT f.*, ROW_NUMBER() OVER (
    PARTITION BY f.component_id ORDER BY f.updated_at DESC
  ) as rn FROM files f
  WHERE is_active = 1
)

3. 배포 및 이전 가이드

🖥️ 인프라 구성 추천

포트 설정 안내: 본 프로젝트는 현재 다음 포트를 사용하도록 설정되어 있습니다.
  • Frontend: 3100
  • Backend: 8180
  • 역방향 프록시 (NGINX):
    • /api 경로 -> 8180 포트 (Back)
    • / 경로 -> 3100 포트 (Front)
  • 프로세스 관리: PM2를 사용하여 서버 재부팅 시 자동 실행 설정.

🚀 배포 프로세스 (명령어)

  1. cd back && npm install
  2. cd ../front && npm install && npm run build
  3. pm2 start ecosystem.config.js

4. 주요 경로 가이드

  • back/app.js: 미들웨어, 라우팅, DB 연결 설정 루틴
  • back/mysql/sql.js: 프로젝트 내 모든 데이터베이스 쿼리 집합
  • back/controllers/componentController.js: 등록, 수정, 다운로드 핵심 로직
  • front/src/app/_types/manage/manage.types.ts: 주요 데이터 타입 정의
  • front/src/app/_components/common/manage: 목록 및 UI 컴포넌트
